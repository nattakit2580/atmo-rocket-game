# จรวดข้ามบรรยากาศ 5 ชั้น

เกม 2D ที่ควบคุมจรวดด้วยการ**ยกแขน**ผ่านกล้อง (ตรวจจับตั้งแต่หัวไหล่ถึงปลายนิ้ว ด้วย MediaPipe Pose)
ยกแขนขวา -> จรวดขยับขวา, ยกแขนซ้าย -> จรวดขยับซ้าย ต้องหลบของที่ตกลงมาให้ผ่านบรรยากาศทั้ง 5 ชั้น
จบแต่ละด่านจะมีความรู้เกี่ยวกับชั้นบรรยากาศและของที่ตกลงมาในด่านนั้น

## โครงสร้างไฟล์
- `main.py` — เกมหลัก (state machine, HUD, การชน, จอความรู้ท้ายด่าน)
- `camera_control.py` — เธรดกล้อง + MediaPipe Pose Landmarker ตรวจจับแขน
- `entities.py` — จรวดผู้เล่น และของที่ตกลงมาแต่ละแบบ (วาดด้วย pygame ล้วน ไม่ใช้รูปภายนอก)
- `levels_data.py` — ข้อมูล 5 ด่าน (ชื่อชั้น, สี, ของที่ตกลงมา, ความรู้ท้ายด่าน)
- `models/pose_landmarker_lite.task` — โมเดล Pose ของ Google MediaPipe (ต้องอยู่คู่กับโปรแกรมเสมอ)
- `build.spec` — ไฟล์สั่งแพ็กเป็น .exe ด้วย PyInstaller
- `dist/AtmoRocketGame.exe` — ไฟล์เกมที่แพ็กเสร็จแล้ว รันได้เลยไม่ต้องติดตั้ง Python

## วิธีเล่น
- **ยกแขนขวา** (ไหล่ถึงปลายนิ้วยกขึ้นเหนือระดับไหล่) -> จรวดขยับไปทาง**ขวา**
- **ยกแขนซ้าย** -> จรวดขยับไปทาง**ซ้าย**
- ไม่ยกแขนข้างไหนเลย (หรือยกทั้งสองข้างพร้อมกัน) -> จรวดหยุดอยู่กับที่
- ถ้ากล้องตรวจจับไม่ได้ ใช้ปุ่ม **ลูกศรซ้าย/ขวา** หรือ **A/D** แทนได้ทันที (สลับไปมาได้อัตโนมัติ)
- กด **C** เพื่อเปิด/ปิดการควบคุมด้วยกล้อง
- กด **SPACE/ENTER** เพื่อเริ่มเกม/ไปด่านต่อไป/เริ่มใหม่
- กด **ESC** เพื่อออกจากเกม
- มีชีวิต 3 ดวง ถ้าชนของที่ตกลงมาจนหมดชีวิต -> เกมโอเวอร์ เริ่มใหม่จากด่าน 1

มีกล่องพรีวิวกล้องที่มุมขวาบนของหน้าจอ พร้อมเส้นโครงร่างแขนและลูกศรบอกทิศทางที่ตรวจจับได้
เพื่อช่วยให้ปรับท่ายืน/ระยะห่างจากกล้องได้ง่าย

## วิธีรันแบบไฟล์ .exe (ไม่ต้องติดตั้งอะไรเพิ่ม)
ดับเบิลคลิก `dist/AtmoRocketGame.exe` ได้เลย (มีหน้าต่าง console โผล่มาด้วยเพื่อโชว์ error ถ้ามี)
ถ้า Windows Defender/SmartScreen เตือนเพราะเป็นไฟล์ไม่รู้จัก ให้กด "More info" -> "Run anyway"
(เกิดเพราะไฟล์ไม่ได้เซ็นใบรับรองโค้ด ไม่ใช่ปัญหาไวรัส)

## วิธีรันจากซอร์สโค้ด (สำหรับแก้ไข/พัฒนาต่อ)
```powershell
cd C:\Users\asus\atmo-rocket-game
.venv\Scripts\python.exe main.py
```
ถ้ายังไม่มี venv หรือย้ายเครื่อง ให้สร้างใหม่:
```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## วิธี build .exe ใหม่หลังแก้โค้ด
```powershell
cd C:\Users\asus\atmo-rocket-game
.venv\Scripts\python.exe -m PyInstaller build.spec --noconfirm
```
ไฟล์ผลลัพธ์จะอยู่ที่ `dist\AtmoRocketGame.exe`

**สำคัญ:** ต้อง build (และควรรันตอนพัฒนา) จากโฟลเดอร์ที่เป็น**ตัวอักษรอังกฤษล้วน**เท่านั้น
(ห้ามอยู่ใต้โฟลเดอร์ที่มีชื่อภาษาไทย เช่น "เดสก์ท็อป" ของ OneDrive)
เพราะไลบรารี MediaPipe มีบั๊กเปิดไฟล์โมเดลไม่ได้ถ้า path มีอักษรที่ไม่ใช่ ASCII — เจอปัญหานี้จริงระหว่างพัฒนา
จึงต้องย้ายโปรเจกต์มาไว้ที่ `C:\Users\asus\atmo-rocket-game` แทน
ส่วน **ตัว .exe ที่ build เสร็จแล้ว วางไว้ตรงไหนก็ได้ รวมถึงบน Desktop ภาษาไทย** เพราะตอนรัน PyInstaller
จะแตกไฟล์แนบไปไว้ใน temp folder ของ Windows (ภาษาอังกฤษเสมอ) ไม่ใช่ที่ตั้งของ .exe เอง

## ปรับความยาก / เนื้อหาแต่ละด่าน
แก้ที่ `levels_data.py`:
- `duration` = เวลาที่ต้องอยู่รอดในด่านนั้น (วินาที)
- `spawn_interval` / `fall_speed` = ความถี่และความเร็วของที่ตกลงมา
- `objects` = รายการของที่ตกในด่านนั้น แต่ละอันมี `label` (ข้อความ), `shape` (อ้างอิงฟังก์ชันวาดใน `entities.py`),
  `color`, `size`, `fact` (ความรู้ที่จะโชว์ตอนจบด่าน)

## แก้ความไว/ระยะการตรวจจับแขน
แก้ที่ `camera_control.py`:
- `RAISE_THRESHOLD` = ต้องยกแขนสูงกว่าไหล่เท่าไหร่ถึงจะนับว่า "ยก" (ค่าเริ่มต้น 0.06 = 6% ของความสูงภาพ)
- `SMOOTHING` = ความลื่นของการเคลื่อนที่ (0-1 ยิ่งสูงยิ่งลื่นแต่ตอบสนองช้าลง)
